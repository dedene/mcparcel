# MCParcel brand

Chosen on 4 October 2026: the "Shell Parcel" concept. An open parcel
tray holds a command prompt: tools delivered through the terminal.

## Files

| File | Use |
| --- | --- |
| `mark.svg` | The mark alone. Three strokes, no fills, safe down to 16 px. |
| `logo-light.svg` | Mark plus wordmark for light backgrounds. |
| `logo-dark.svg` | Mark plus wordmark for dark backgrounds. |

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Olive | `#85934B` | The mark, accents, focus rings. Not for body text on light backgrounds (contrast about 3:1). |
| Olive deep | `#5F6B2F` | Olive text and links on light backgrounds (contrast above 4.5:1). |
| Olive light | `#A9B76A` | Olive text and links on dark backgrounds. |
| Warm white | `#F4F4EC` | Light background, text on dark. |
| Charcoal | `#252B25` | Dark background, text on light. |

## Type

The wordmark and all interface text use the system monospace stack
(`ui-monospace, "SF Mono", Menlo, Consolas, monospace`), bold for the wordmark.
No font file is bundled, so the sign-in page needs no external request and no
font licence.

## Construction

The mark sits on a 50 × 32 grid. The tray is one 6-unit stroke, open at the
top. The prompt chevron and the underscore are 4.5-unit strokes with square
ends. Keep clear space of one tray-stroke width around the mark. Do not round
the corners, fill the tray or recolour the strokes separately.
